# Descripcion general
Esta aplicacion se realizo para eliminar el proceso tedioso y repetitivo de la reviso de devices para las maquinas Fuji CP6
## Imagen de un reporte generado por software Flexa:
Como se observa es necesario abrir tres pestañas de navegador para generar un solo device para posterior imprimirlo, la aplicacion tiene la capacidad para generar los mismos reportes y personalizarlos en base a los xml que genera el software Flexa.
![image](https://github.com/user-attachments/assets/a757c79c-3ca7-4d09-b977-c2753bcae301)
haciendo al ComparadorV2 mas eficiente y ahorrando tiempo con tareas repetitivas.
